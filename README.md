# Noa Ellsworth

Next.js portfolio with a WebGL point-cloud hero — a botanist portrait built from 66,000 dots.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

- `components/hero` — full-viewport hero section (UI + Three.js scene)
- `app/page.tsx` — homepage that mounts the hero
- `public/fonts` — Geist, Geist Mono, Instrument Serif
